## Test Tool Decision
Playwright choose kiya gaya because:
- Ubuntu/Linux par stable hai.
- Official Docker image available hai.
- Chromium, Firefox, aur mobile Chromium ek hi runner se cover ho jate hain.
- Dockerized website ko black-box mode me test kar sakta hai.
- Attendance GPS flow ke liye browser geolocation mocking support karta hai.

## Docker Runner
Playwright ke liye separate compose file add ki gayi:

```bash
docker compose -f docker-compose.e2e.yml run --rm playwright
```

Compose image:

```text
mcr.microsoft.com/playwright:v1.53.0-noble
```

## Environment Variables
Default base URL:

```bash
E2E_BASE_URL=https://attendance.sampledge.duckdns.org
```

Authenticated suites ke liye:

```bash
E2E_USER_USERNAME=
E2E_USER_PASSWORD=
E2E_ADMIN_USERNAME=
E2E_ADMIN_PASSWORD=
```

Mutation tests default off hain:

```bash
E2E_ALLOW_MUTATION=false
```

Clock-in/out ya future CRUD mutation run karne ke liye disposable test data par:

```bash
E2E_ALLOW_MUTATION=true
```

## Run Commands
Basic public/auth-independent tests:

```bash
docker compose -f docker-compose.e2e.yml run --rm playwright
```

Authenticated tests:

```bash
E2E_USER_USERNAME=user@example.com \
E2E_USER_PASSWORD='password' \
E2E_ADMIN_USERNAME=admin@example.com \
E2E_ADMIN_PASSWORD='password' \
docker compose -f docker-compose.e2e.yml run --rm playwright
```

Target override:

```bash
E2E_BASE_URL=http://localhost docker compose -f docker-compose.e2e.yml run --rm playwright
```
