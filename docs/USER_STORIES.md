# User Stories - Mini HRMS

## 1. Employee (User) Stories

### Attendance & Dashboard
- **US1.1:** As an employee, I want to clock in with my GPS location so that my presence at the field site is verified.
- **US1.2:** As an employee, I want to see a real-time clock on my dashboard so that I can accurately track my shift start time.
- **US1.3:** As an employee, I want to see a history of my clock-in/out events for the day so that I can confirm my entries were recorded.
- **US1.4:** As an employee, I want to view my attendance records for a specific date range so that I can check for any missing marks.

### Leaves & Holidays
- **US1.5:** As an employee, I want to apply for leave by specifying dates and reason so that my manager can approve it.
- **US1.6:** As an employee, I want to view the status of my leave applications so that I can plan my time off.
- **US1.7:** As an employee, I want to view the holiday calendar so that I know which days are non-working.

## 2. Administrator Stories

### User Management
- **US2.1:** As an admin, I want to add new employees to the system so that they can start recording their attendance.
- **US2.2:** As an admin, I want to deactivate resigned employees so that they no longer have access to the system.
- **US2.3:** As an admin, I want to reset an employee's password so that they can regain access if they forget it.

### Configuration & Policy
- **US2.4:** As an admin, I want to configure branches and departments so that the organizational structure is represented.
- **US2.5:** As an admin, I want to set shift timings and late-coming policies so that attendance can be automatically validated.
- **US2.6:** As an admin, I want to manage the holiday list so that the system can correctly calculate working days.

### Verification & Reporting
- **US2.7:** As an admin, I want to manually correct an employee's attendance mark so that errors can be fixed with an audit trail.
- **US2.8:** As an admin, I want to verify (check-mark) attendance records so that they are ready for payroll processing.
- **US2.9:** As an admin, I want to generate monthly attendance reports so that I can track overall employee performance.
